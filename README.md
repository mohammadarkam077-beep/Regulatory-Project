Road Accident Data Analysis – India (2020)
📌 Overview

This project performs Exploratory Data Analysis (EDA) on the Road Accident Data 2020 – India dataset to study accident outcomes such as Persons Killed, Injured, and Total Accidents across million-plus cities.
The analysis focuses on cause-wise and city-wise trends to support insights relevant to road safety and regulatory decision-making.

📂 Dataset

File: Regulatory Affairs of Road Accident Data 2020 India.csv
Size: 9550 rows × 5 columns

Columns

million_plus_cities – City name

cause_category – Major cause of accident

cause_subcategory – Specific sub-cause

outcome_of_incident – Accident outcome

count – Number of cases

Outcome Types

Persons Killed

Total Injured

Greviously Injured

Minor Injury

Total number of Accidents

🧪 Analysis Workflow

Load and inspect dataset

Filter data based on accident outcomes (e.g., Persons Killed)

City-wise aggregation using groupby()

Cause-wise and sub-cause-wise analysis

Visualization using bar charts and pie charts

📊 Key Visualizations

City-wise distribution of persons killed

Cause category-wise fatalities (bar charts)

Cause subcategory contribution (pie charts)

Top 3 cities for each cause subcategory

🧠 Key Insights

Certain million-plus cities consistently show higher fatality counts

Human-related causes (e.g., over-speeding) dominate fatal accidents

Sub-cause analysis helps identify specific regulatory gaps
